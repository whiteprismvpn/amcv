# AMCV

## Редактируемое резюме

Публичная страница находится на `/`, а интерфейс владельца — на `/admin`.

### Защита админки

1. В Cloudflare Access создайте правило, разрешающее доступ к `/admin` только вашему email.
2. В настройках Cloudflare Workers добавьте секрет `ADMIN_TOKEN`; никогда не коммитьте его в GitHub.
3. Для сохранения данных между деплоями создайте KV namespace и привяжите его как `RESUME` в `wrangler.json`.

В текущей реализации API принимает данные только с заголовком `Authorization: Bearer <ADMIN_TOKEN>`. Без корректного секрета оно возвращает `401`, поэтому посетители не смогут сохранять изменения.

Начальные сведения расположены в `src/data/resume.ts`. Их можно заменить напрямую в коде либо через будущую форму, подключённую к KV/D1.
